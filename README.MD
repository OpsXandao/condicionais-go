# 🔁 Condicionais em Go

Este projeto demonstra o uso de estruturas condicionais (`if`, `else` e `switch`) na linguagem [Go (Golang)](https://go.dev/), com exemplos práticos para iniciantes.

---

## 🧠 O que você vai aprender

- Como usar `if` e `else` em funções
- Como utilizar `switch` para múltiplos casos
- Boas práticas para controle de fluxo em Go
- Como retornar mensagens personalizadas a partir de condições

---

## 📁 Arquivos

| Arquivo         | Descrição                                      |
|------------------|-----------------------------------------------|
| `main.go`        | Exemplo simples com `switch` (saudação por turno) |
| `exercicio.go`   | Atividade   |
| `go.mod`         | Módulo Go com nome do repositório             |
| `README.md`      | Este arquivo 😄                               |

go run main.go
